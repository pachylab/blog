성범죄 -> Autopsy, EXIF 분석, PhotoDNA(해시 매칭)

SSD, 모바일  
-> 파일 삭제 시 0으로 덮혀버림. 복구 어려움

HDD
- 물리 이미징으로 전체 복사 가능
- 슬랙 공간(slack space)에 데이터 잔존
- 삭제파일 -> 비할당 영역에서 복구
- 배드 섹터 영역도 분석 가능

SSD
- TRIM 명령 -> 포렌식의 적!
- TRIM 비활성화 또는 빠른 수집 필요
- OS가 삭제 파일 명령을 SSD에 통보. SSD 컨트롤러가 자동으로 데이터 소거.
- NAND 플래시 메모리 + 컨트롤러
- 웨어 레벨링 적용

```
NTFS, FAT32  -> 매우매우 중요
```
NTFS
- MFT
- ADS 지원

FAT32
- 최대 파일 크기 4GB

diskmgmt.msc 
- 장치 인스턴스 경로 : NVMe 이면 SSD 이다.

> [!note] Mac OS
> plist, FSEvents, Spotlight, United Log, Key chain, APES 스냅샷


### 아티팩트
- LNK 파일
- 휴지통: $Recycle.Bin
  - shift + delete: 휴지통 안 거치고 삭제
- 프리패치: 실행 이력, 실행 횟수
  - C:\Windows\Prefetch
- 썸네일
- 웹 브라우저
- 레지스트리
- AmCache: 설치,실행 기록
  - C:\Windows\appcompat\Programs
- 이벤트로그
  - C:\Windows\System32\winevt\Logs
- MFT: 파일 메타데이터
- USN저널: 파일 변경 이력

# gdb

## 용도

Linux native debugging, crash 분석, register/stack/memory 확인.

## 먼저 익힐 것

- breakpoint
- `run`, `continue`, `si`, `ni`
- `info registers`
- `x/20gx $rsp`
- `disassemble`

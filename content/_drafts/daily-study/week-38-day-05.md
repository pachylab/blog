# Week 38 Day 05: patch design와 regression test

## 오늘의 목표

- patch design, bounds check, integer validation를 자료의 정의, 실습 관찰, 보안 분석 쓰임으로 나누어 설명한다.
- memory safety, regression test, negative test가 실제 artifact, primitive, IOC, evidence 중 어디에 연결되는지 예시를 남긴다.
